# Joginho de Inglês – Ensino Fundamental

Provinha interativa para treinar o vocabulário da prova oral de inglês.

**Jogar:** https://r0f0el.github.io/Joginho-fundamental-ingles/

## Conteúdo

| Parte | Palavras |
|---|---|
| Wild Animals (Animais selvagens) | elephant, monkey, bear, giraffe, crocodile, tiger |
| Colors (Cores) | gray, brown, black, yellow, green, orange |
| Feelings (Sentimentos) | excited, bored |
| Foods (Alimentos) | fish, corn, tomato, salad |
| Translate (Tradução) | 6 palavras sorteadas entre as de cima |

## Como jogar

1. Toque numa **palavra** — o celular fala a pronúncia em inglês.
2. Toque na **figura** certa. Acertou: fica verde. Errou: treme e fica vermelha.
3. Toque numa figura já acertada para ouvir a palavra de novo.
4. **Recomeçar** sorteia uma nova ordem.

A ordem das partes, das figuras e das palavras muda a cada jogo, para a criança não decorar a posição.

## Dica para treinar em casa

Depois de jogar, aponte para cada figura e pergunte **"What's this?"** (O que é isto?). A criança responde em voz alta, em inglês.

## Tecnologia

Um único `index.html` (HTML, CSS e JavaScript puro), sem instalação. A pronúncia usa a voz do próprio navegador (Web Speech API).
